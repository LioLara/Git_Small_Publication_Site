Semantic tokens are used instead of repeating raw values. These tokens help create consistency across the design system.

Typography

--font-body Arial, Helvetica, sans-serif Body copy and interface text
--font-display Georgia, "Times New Roman", serif Headings and display text
--font-size-base 1rem Default body
--font-size-xl 1.75rem Large headings
--line-height-base 1.6 Paragraph spacing

Spacing

--space-xs 0.25rem Very tight spacing for closely related elements
--space-sm 0.5rem Small gaps between related items
--space-md 1rem Default component spacing
--space-lg 1.5rem Large spacing
--space-xl 2rem Spacing for content groups
--space-xxl 3rem Section spacing

Sizing and Measure

--content-max 72rem Maximum width for the overall page content
--text-measure 65ch Maximum readable line length for body text

Radius

--radius-sm 0.25rem Small rounded corners
--radius-md 0.5rem Default rounded corners
--radius-lg 1rem Larger rounded corners

Elevation

--shadow-sm 0 1px 2px rgb(0 0 0 / 0.08) Slight elevation for cards
--shadow-md 0 4px 12px rgb(0 0 0 / 0.12) Stronger elevation for more prominent surfaces

S3 Typography

The typography uses a serif display stack for headings and a sans serif body stack for the content.

Font source is just system fonts. Didn't see a need to go with other custom fonts when the generic one works well. So, no external font files or licenses are needed.

Fallback Behavior

Because I went with the most widely used default font stack, the body will automatically fall back to helvetica and then the browser's default sans serif font. Then if Georgia is unavailable, the display text goes to times new roman followed by the browser's serif font.

S4 Actions / States

Accessibility maintained and action states are clearly indicated for buttons and links.

Text Link

Read more in this example article link.

Buttons

Primary buttons vs secondary buttons. I like to think of it like a login and forgot password button. Login primary, forgot password secondary. Disabled buttons remain visible but unavailable, and all interactive elements preserve clear hover, active, and keyboard focus states. Even added a little cursor icon to indicate a disabled link.
